## 说明

- **页面/弹窗（54）**：静态声明的页面与弹窗类；其中侧边栏直达 5 个、二级页签 10 个、三级页面 22 个、弹窗/向导 15 个。
- **按钮（101）**：`JFXButton` / `Button` / `LineButton` / `Hyperlink` / `MenuButton` / 强调按钮。
- **列表项/开关（62）**：`LineToggleButton` / `LineSelectButton` / `AdvancedListItem` / `CheckBox` / `RadioButton` / `ToggleButton` / 可点击面板。
- **页签（20）**：`new TabItem<>` 的静态声明数。
- **未计入**：随数据动态生成的行（实例、模组、世界、截图等）、右键菜单项、`construct/` 共享控件内部按钮。
- **验收注意**：实现已偏离基线的地方（加载器位置迁移、账户皮肤入口、7→6 页签、个性化 11→1 等）统一记录在 `ui-status.md` §2；基线本身的口径 bug 见该文件 §6。

> 逐层按钮明细（可直接勾选预留）见 `ui-tree-controls.html`；状态标记见 `ui-status.md`。
